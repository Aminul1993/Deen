    Upload files

    Pick a text, or type a new name to create one (letters, digits, - and _).
    What the files are written in. The books page lists books in each reader's language first.
    .txt, .md, .pdf, .json, .jsonl or .csv, up to 200 MB each (.json up to 50 MB; use .jsonl for bigger record files). PDFs are also kept as books that anyone can read on the books page.
    A direct link to one of those file types, up to 200 MB. The server downloads it, then adds it like an uploaded file.
    How files are split and cited
    • .txt, .md: split into passages of about 1,000 characters.
    • .pdf: the text of each page, split the same way, with its page number. Pages without readable text (scanned, or set in an old non-Unicode font such as Bijoy) are read with OCR (OCR.space) in the language chosen above, if the server has an OCR.space key; that takes a few seconds a page. Its free plan reads 1,000 Bengali, Arabic or Urdu pages a month. Pages OCR can't read yet, e.g. once that limit is reached, are marked in the list of files below, to be read again later. The PDF itself is kept too, from a file or a web address, so anyone can read it page by page on the public books page, and an answer's sources link to the page each passage came from. Deleting the file removes the book.
    • .json, .jsonl, .csv: one record per array item, line or row. Each record needs a text (or content) field. Its other fields are kept, so answers can cite them: surah and ayah for the Quran; collection, hadith_number, grade and book for hadith. 
      {"text": "Actions are judged by intentions…", "collection": "Sahih al-Bukhari", "hadith_number": 1, "grade": "Sahih"}
    • Files uploaded to the text named duas or namaz can also be read one by one from the chat page's Duas or Namaz Shikkha button, in upload order. Put Namaz Shikkha steps in the order they're done. Give each record a text (the meaning or instruction) and, if you have them, section (e.g. Wudu), title, arabic, transliteration and its source, such as surah and ayah, or collection, hadith_number and grade. 
      {"title": "For good in both worlds", "arabic": "رَبَّنَا آتِنَا فِي الدُّنْيَا حَسَنَةً وَفِي الْآخِرَةِ حَسَنَةً وَقِنَا عَذَابَ النَّارِ", "transliteration": "Rabbana atina fid-dunya hasanatan wa fil-akhirati hasanatan wa qina 'adhaban-nar", "text": "Our Lord, give us good in this world and good in the Hereafter, and protect us from the punishment of the Fire.", "surah": 2, "ayah": 201}
    • Uploading a file with the same name to the same text again replaces the earlier version, and keeps its place in a reader. A file from a web address is named after the address (or the name the site gives it), so downloading the same address again replaces it too.
